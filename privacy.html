アプリ「富山ニュース投稿」の個人情報の取り扱いについて

このアプリについて

「富山ニュース投稿」（以下「本アプリ」）は、YouTube チャンネル「とやまもん」の運営者が、自分で作った動画を自分のチャンネルへアップロードするためだけに使う個人用ツールです。一般の方に提供するものではありません。

利用する情報と目的

  • 本アプリは、Google アカウントの許可画面で運営者本人が許可した範囲（YouTube への動画のアップロード：youtube.upload）だけを使います。
  • 使い道は、運営者のチャンネルへの動画のアップロードと、その動画のタイトル・説明・サムネイルの設定に限ります。
  • 動画の再生履歴、コメント、登録チャンネル、連絡先など、ほかの情報は読み取りません。

保存と共有

  • 許可の情報（アクセストークン）は、運営者のパソコンの中にだけ、本人しか読めない形で保存します。外部のサーバーには保存しません。
  • Google から受け取った情報を、第三者に販売・提供・共有することはありません。広告にも使いません。
  • 本アプリによる Google API から受け取った情報の利用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

YouTube API サービスについて

本アプリは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約 が、情報の取り扱いには Google プライバシーポリシー が適用されます。

許可の取り消しと削除

本アプリへの許可は、Google アカウントのセキュリティ設定 からいつでも取り消せます。取り消すと、本アプリは YouTube にアクセスできなくなります。パソコンに保存した許可の情報も、運営者が削除します。

English summary

"富山ニュース投稿" is a personal tool used only by the owner of the YouTube channel "とやまもん". It uses only the youtube.upload scope, solely to upload the owner's own videos (and set their titles, descriptions and thumbnails) to the owner's own channel. No other data is read. Access tokens are stored only on the owner's computer and are never sold, shared or transferred to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
