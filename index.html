とやまもん富山ニュース

富山県のニュースを、朝と夜にまとめてお届けする YouTube チャンネルです。

チャンネルについて

毎朝・毎晩、富山県内で話題になったニュースを注目度の高い順に10本まとめ、短い動画でご紹介しています。

内容は各報道機関の記事で事実を確かめたうえで要約し、出典は動画の画面と概要欄に載せています。ナレーションは VOICEVOX:冥鳴ひまり です。

アプリ「富山ニュース投稿」について

「富山ニュース投稿」は、このチャンネルの運営者が自分で作った動画を、自分の YouTube チャンネルへ 非公開 でアップロードするための個人用ツールです。YouTube Data API を使い、動画のアップロードとサムネイルの設定だけを行います。

運営者以外の方が使うことはなく、ほかの方のアカウントや情報を扱うこともありません。詳しくは プライバシーポリシー をご覧ください。

"富山ニュース投稿" (Toyama News Uploader) is a personal tool used only by the channel owner to upload their own videos to their own YouTube channel as private, via the YouTube Data API. See the Privacy Policy.
